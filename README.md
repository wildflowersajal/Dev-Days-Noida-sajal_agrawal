# Memory Genie

A warm family memory companion prototype for older adults and caregivers.

## Features

- welcoming dashboard
- memory garden with six sample memories
- add, edit, delete, and search memories
- image preview when uploading photos
- gentle moments prompts
- life threads timeline
- localStorage persistence for prototype use
- responsive and accessible design

## Run it locally

1. `npm install`
2. `npm run dev`
3. Open the local Vite URL shown in the terminal.

## Build

- `npm run build`

This prototype uses fictional sample data only and does not diagnose or treat memory conditions.
